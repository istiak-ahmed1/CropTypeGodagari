# CropTypeGodagari
### Functional Data Analysis and Machine Learning for Remote Sensing-Based Crop Type Mapping in Small Holding Farms of Bangladesh
This study mapped six Rabi crops (rice, wheat, lentil, maize, mustard, and potato) in Godagari Upazila, Rajshahi, by modeling each field's seasonal index measurements as a smooth curve over time and combining functional data analysis with machine learning. Field-reference points from three seasons (2020-21 to 2022-23) were quality-screened against the Dynamic World land-cover product and additional duplicate, mixed-pixel, and low-vegetation checks, leaving 1,290 clean points. For each point, twelve Sentinel-2 and Sentinel-1 indices were summarised as regular 15-day composites over November-April (twelve-time steps) and smoothed into continuous curves using B-splines. Functional analysis of variance showed that all 12 indices differed significantly among crops (p < 0.001), and the Jeffries-Matusita distance analysis confirmed near-complete separability for most crop pairs. Functional principal component scores were used as compact features for five classifiers, compared using both spatial-block and leave-one-year-out cross-validation. A tuned LightGBM model was selected and achieved an overall accuracy of 0.860 (95% CI 0.841-0.878), a Cohen's kappa of 0.821, and a macro-averaged F1 of 0.838; rice and potato were mapped most accurately (F1 = 0.94 and 0.91), and lentil was least accurately (F1 = 0.70). The first functional component of Sentinel-1 VV backscatter was the most influential feature. Applied across the upazila for 2022-23, the model estimated rice (32.0%) and mustard (22.5%) as the dominant Rabi crops. The workflow shows that combining optical-radar phenology, automated reference-data quality control, functional statistics, and spatially honest validation yields an accurate and reproducible framework for crop-type mapping in smallholder landscapes.
